# Fixture Notes requirements (bundle id dev.agentictests.fixturenotes)

1. On launch the screen is titled "Fixture Notes" and lists two notes, "Welcome" and "Groceries", with the count "2 notes".
2. Typing a note in "New note" and tapping "Add" appends it to the list, clears the field and increases the count by one.
3. Adding an empty note shows "Note cannot be empty" and adds nothing.
4. Adding a note that already exists shows "Note already exists" and adds nothing.
